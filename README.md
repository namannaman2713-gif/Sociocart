# SocioCart — VS Code project

## Files
- `index.html` — page structure
- `styles.css` — design and responsive styling
- `script.js` — demo shopping cart, checkout, tracking, delivery partner and admin interactions

## Run locally
1. Open this folder in Visual Studio Code.
2. Install the **Live Server** extension (if needed).
3. Right-click `index.html` and choose **Open with Live Server**.
   You can also open `index.html` directly in a browser for this front-end-only demo.

## Important
This is a front-end prototype. Orders are demo-only and stored in browser memory; there is no backend, real payment processing, or actual delivery. Refreshing the page resets the in-memory demo state.
